# Benchmark provenance

`qiskit_humaneval.json` and `qiskit_humaneval_hard.json` are unmodified copies of
`dataset/dataset_qiskit_test_human_eval.json` and `dataset/dataset_qiskit_test_human_eval_hard.json`
from https://github.com/qiskit-community/qiskit-human-eval (main branch, fetched 2026-10-18),
licensed under the Apache License 2.0 (`LICENSE-qiskit-human-eval`). Copyright the Qiskit HumanEval authors.

Benchmark paper: *Qiskit HumanEval: An Evaluation Benchmark for Quantum Code Generative Models*.

`validation_standard.json` and `validation_hard.json` are generated by this project
(`python -m qiskit_repair_agent.cli validate-tasks`). They record, for each task, whether the canonical
solution passes in our sandbox and whether a null stub (`return None`) is correctly rejected.
